# Security Policy

## Reporting a vulnerability

Report suspected vulnerabilities privately through the repository's GitHub
private vulnerability reporting ("Report a vulnerability" under the Security
tab). Please do not open a public issue or pull request for a security
problem, and do not include exploit details in a public discussion.

Include what you can: affected version or commit, what an attacker can do, and
the steps to reproduce. Use invented data in any reproduction you attach.

## What happens next

Reports are acknowledged and triaged privately. A fix is prepared and reviewed
on the Jeryu forge, and the mirror push publishes it here. We will keep you
updated through the private report thread and credit you in the release notes
unless you ask us not to.
